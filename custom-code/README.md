# Customizações próprias

Use esta pasta somente para trechos de HTML, CSS ou JavaScript que você efetivamente criou para o website e tem autorização para divulgar.

Para cada arquivo, documente a página afetada, a finalidade, como foi aplicado no WordPress/Elementor e como validar o resultado.

Não copie arquivos de plugins ou temas comerciais, bibliotecas de terceiros sem licença compatível, credenciais ou código proprietário.
