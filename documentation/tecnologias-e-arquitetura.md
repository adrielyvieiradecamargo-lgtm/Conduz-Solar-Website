# Tecnologias e arquitetura

## Plataforma publicada

- CMS: WordPress.
- Editor visual: Elementor.
- Hospedagem: HostGator (informação fornecida no contexto do projeto).
- Endereço público: https://conduzsolar.com.br/

## Modelo de funcionamento

O WordPress é executado no ambiente de hospedagem, normalmente com PHP e banco de dados. O navegador recebe o HTML, CSS, JavaScript, imagens e demais recursos necessários para renderizar as páginas.

O GitHub deste portfólio guarda documentação e arquivos próprios autorizados. Ele não substitui o ambiente WordPress nem executa o CMS por meio do GitHub Pages.

## Possíveis arquivos versionáveis

- CSS adicional desenvolvido especificamente para o site.
- JavaScript autoral, se houver.
- Trechos HTML autorais, se houver.
- Documentação de componentes e configurações.
- Capturas de tela autorizadas.

## Como registrar uma customização

Para cada customização, documentar:

1. Objetivo do ajuste.
2. Página ou componente afetado.
3. Arquivo ou local do WordPress em que foi aplicado.
4. Código autoral (sem credenciais ou código de terceiros).
5. Como testar e reverter.
6. Data da alteração.

Não atribuir ao projeto tecnologias, integrações ou funcionalidades sem confirmação no ambiente real.
